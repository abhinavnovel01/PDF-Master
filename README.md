## 📌 About the Project

**PDF Master** is a simple and efficient web-based tool designed to handle common PDF operations directly from your browser. It provides a clean interface for converting and optimizing documents without requiring any additional software installation.

The application focuses on speed, ease of use, and accessibility, making document handling straightforward for all users.

---

## 🚀 Features

- 📄 **PDF to Word Conversion**
  - Convert PDF files into editable Word documents
  - Preserves text structure for easy editing

- 📝 **Word to PDF Conversion**
  - Convert DOCX files into professional PDF format
  - Ideal for sharing and printing documents

- 📉 **PDF Compression**
  - Reduce file size efficiently
  - Multiple compression levels:
    - Low (Smallest Size)
    - Medium (Balanced)
    - High (Best Quality)

- ⚡ **Fast Processing**
  - Quick file conversion and compression

- 🔒 **Secure Handling**
  - Files are processed temporarily and safely

- 🌐 **Browser-Based**
  - No installation required
  - Works directly online

## 🛠️ Tools & Technologies

- **Frontend & Backend**
  - Streamlit

- **Programming Language**
  - Python

- **Libraries Used**
  - `pypdf` – PDF processing
  - `python-docx` – Word document handling

- **System Utilities**
  - LibreOffice – File conversion engine
  - Ghostscript – PDF compression

## ⚙️ How to Use

1. Open the app  
2. Select a feature (Convert or Compress)  
3. Upload your file  
4. Choose desired options  
5. Click the action button  
6. Download the processed file
